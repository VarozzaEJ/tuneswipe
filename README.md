## 📖 Overview

TuneSwipe is an interactive web application that transforms music discovery into a fun and intuitive experience. Using Spotify's rich music library, TuneSwipe allows users to discover new music with a simple swipe interface - swipe left to save songs to your Spotify library, swipe right to skip to the next track. The app also features a social component where users can share their musical discoveries with the community.

## ✨ Features

- **Intuitive Swipe Interface**: Swipe left to save songs to your Spotify library, right to skip
- **Personalized Recommendations**: Get music recommendations based on your listening history and preferences  
- **Spotify Integration**: Seamlessly connects with your Spotify account for a unified experience
- **Social Sharing**: Post songs to express your musical taste and connect with like-minded listeners
- **Responsive Design**: Optimized for both desktop and mobile experiences
- **User Profiles**: Customize your profile to showcase your musical identity

## 🚀 Tech Stack

TuneSwipe is built using modern web technologies:

- **Frontend**:
  - React with TypeScript and JavaScript
  - Tailwind CSS for responsive styling
  - Redux for state management
  - React Router for navigation

- **Backend**:
  - Node.js with Express
  - MongoDB for user data and preferences storage
  - Spotify Web API for music streaming and recommendations
  - JWT for secure authentication

- **APIs**:
  - Spotify API for music data and playback
  - Last.FM API for extended music recommendations

## 🔍 Usage

### Getting Started

1. Sign in with your Spotify account
2. Allow the necessary permissions for TuneSwipe to access your Spotify data
3. Choose an artist and get recommended songs similar to the artist you chose
4. Start swiping to discover and save new music!

### Key Features

#### Music Discovery

![TuneSwipe Discovery Interface](path-to-images/discovery-interface.png)

The main interface presents songs one at a time with album art, artist information, and playback controls. Swipe left to add the current song to your Spotify library, or swipe right to skip to the next recommendation.

#### User Profile

![TuneSwipe User Profile](path-to-images/user-profile.png)

Personalize your profile with your favorite genres, artists, and recently discovered tracks. Your profile serves as your musical identity within the TuneSwipe community.

#### Social Feed

![TuneSwipe Social Feed](path-to-images/social-feed.png)

Share your discoveries with the community and see what others are enjoying. Interact with posts by liking, commenting, or adding songs directly to your own discovery queue.
